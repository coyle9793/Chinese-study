# 学中文 · Chinese Study

A Quizlet-style study site for Chinese Stage 2: flashcards, Learn mode, a matching game, tests, word lists and grammar notes, built from the class slides.

- Study content lives in `data/stage2.json` (one entry per set: cards with characters, pinyin, English and example sentences, plus grammar points).
- Audio uses the browser's built-in Chinese voice. A card with an `"audio"` URL plays that recording instead.
- No build step: open `index.html` through any static web server.
